# Turflijst

Digitale drankenlijst (turflijst) voor de A-kern van Racing Mechelen.

- Eén bestand: `index.html` (vanilla JavaScript, geen build-stap).
- Gegevens worden lokaal in de browser bewaard (`localStorage`).
- De spelerslijst bevat placeholders (`Speler 1`, `Keeper 1`, `Trainer 1`, ...). Echte namen voeg je toe in de app zelf; ze horen niet in deze repo.

## Gebruik

Open `index.html` in een browser. Dat is alles.

Zie [docs/STAND-VAN-ZAKEN.md](docs/STAND-VAN-ZAKEN.md) voor de huidige status en de volgende stappen.
